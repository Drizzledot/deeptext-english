# DeepText

DeepText 是一个面向高中英语教学的 AI 深度文本解析工具。

它不仅生成文章大意，还会从文本证据、底层逻辑、核心洞见、意义语言、教学价值和探究路径等角度进行分析。

## 功能

- Teacher Snapshot
- Underlying Logic
- Evidence
- Core Insight
- Deep Shift
- Meaning-bearing Language
- Teaching Value
- Inquiry Path
- Close Reading
- Transfer

目前支持粘贴英文文本进行分析。
