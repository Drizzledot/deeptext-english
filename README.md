# DeepText

DeepText 是一个面向高中英语教学的 AI 深度文本解析工具。

它不仅生成文章大意，而是尝试从：

- Text Evidence
- Underlying Logic
- Core Insight
- Deep Shift
- Meaning-bearing Language
- Teaching Value
- Inquiry Path
- Close Reading
- Transfer

等角度，为高中英语教师生成可用于备课的深度文本解析报告。

# Codespaces 会自动完成什么？

创建 Codespace 后，系统会自动：

1. 准备 Python 3.12 环境
2. 安装 DeepText 所需依赖
3. 启动 FastAPI
4. 开放 8000 端口
5. 自动打开 DeepText 页面
